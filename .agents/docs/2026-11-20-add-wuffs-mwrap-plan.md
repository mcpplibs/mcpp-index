# Plan and record: mcpplibs.mwrap.wuffs 0.3.6 (compat.wuffs + wuffs-m)

Status: done, 2026-11-20.

## Shape

- `compat.wuffs` 0.3.6 (mcpp-index#855): the tag archive (upstream publishes no release assets); one generated
  translation unit compiles `release/c/wuffs-v0.3.c` under `WUFFS_IMPLEMENTATION` **as C++**, so the C API (in
  `extern "C"`) and `wuffs_aux` (defined only for C++) are one library. Every package built. CN: `mcpp-res/wuffs`.
- `wuffs-m` (`mcpplibs.mwrap.wuffs` 0.3.6): one module per upstream package (`base` and 15 others), `.aux`
  (`wuffs_aux`), `.macros`, a root re-exporting all; generated by `tools/gen_exports.py` from
  `clang++ -Xclang -ast-dump=json -Xclang -ast-dump-filter=wuffs` (every Wuffs name contains "wuffs"), audited by
  `tools/check_exports.py`. CN: `mcpp-res/mwrap-wuffs`.

## Measured surface

429 globals exported; 315 `static inline` functions adapted in `mcpplibs::mwrap::wuffs` (sdl3-m's pattern; defined
non-inline in the interface, since an inline body calling an internal-linkage function is a TU-local exposure);
`wuffs_aux` 36 names; 341 macros: 296 constants (captured type preserved), 34 macros naming functions as constexpr
pointers, 11 listed with reasons (attributes, feature tests, the include guard, the token-pasting
`WUFFS_BASE__SLICE/TABLE/RESULT(T)`). `src/wuffs_aux.cppm`, not `aux.cppm`: AUX is a reserved name on Windows.

## Verification

- `tests/surface_test.cpp` (generated): every adapter's type equals the header function's, every constant equals its
  macro with its type, every alias points at its target — compile time, GCC 16 and Clang 23.
- `tests/api_test.cpp`: every package through the module alone (PNG, GIF, BMP, TGA, WBMP, NIE; DEFLATE, zlib, gzip,
  bzip2; CRC-32, Adler-32; JSON with a JSON pointer, CBOR; numbers, UTF-8, base-64; the error paths).
- Conformance: upstream's `example/convert-to-nia` ported against the module vs upstream's `convert-to-nia.c` on all
  246 files of `test/data`, NIA and NIE: identical bytes, message and exit code; 82/82 checksums of
  `test/nia-checksums-of-data.txt`. CI: Linux x86_64, Linux arm64, macOS arm64 (Windows: the reference needs
  `<unistd.h>`). The reference backports upstream main's end-of-input test: 0.3.6's `errno == 0` reads a stale
  errno where the Linux seccomp call fails (EINVAL on hosts refusing strict mode) and stops a step early.
- wuffs-m CI: 5 rows (Linux gcc/llvm, Linux arm64, macOS, Windows), dev and release; templates job.
- Installed acceptance (this PR): `check_installed_template.py --deploy` on the real archive (template strict build
  and run, relocated bundle, 5 byte-identical notices); member `wuffs-decode` (behavior, side header).
